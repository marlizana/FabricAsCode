árbol del proyecto

fabric-platform/
├── main.tf          # los recursos
├── variables.tf     # las entradas
├── outputs.tf       # las salidas
├── providers.tf     # versiones
├── backend.tf       # estado remoto
└── envs/
    ├── dev.tfvars
    ├── test.tfvars
    ├── qa.tfvars
    └── pro.tfvars

dev.tfvars

# envs/dev.tfvars
entorno     = "DEV"
capacity_id = "f1a2b3c4-..."
capas       = ["bronze", "silver", "gold"]

terminal

$ terraform apply \
    -var-file=envs/dev.tfvars

Un solo código. Cuatro ficheros de valores.

Cambias dev por pro y tienes producción. Exactamente igual que dev, por construcción.
