BLOQUE 3 · CÓMO FUNCIONA

Tres reglas sobre el estado. No negociables.

1

Nunca lo subas a git

Tiene valores en claro, secretos incluidos. *.tfstate al .gitignore el minuto uno.

2

Nunca solo en tu portátil

Si se pierde, Terraform olvida que esos workspaces son suyos e intenta crearlos otra vez.

3

Backend remoto con bloqueo

Una storage account de Azure: estado compartido y dos apply no se pisan.

backend.tf

terraform {
  backend "azurerm" {
    resource_group_name  = "rg-tfstate"
    storage_account_name = "sttfstate001"
    container_name       = "tfstate"
    key                  = "fabric.tfstate"
  }
}

El día que tu equipo sea más de una persona, el backend remoto deja de ser opcional.

32 · Terraform al rescate

Las tres reglas entran solas. Clic para el backend.tf (así de corto es) y otro para el remate.
