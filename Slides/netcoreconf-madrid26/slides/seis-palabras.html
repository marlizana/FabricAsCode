BLOQUE 2 · TERRAFORM

Las seis palabras que componen HCL

resource

Algo que Terraform crea y gestiona.

variable

Un parámetro de entrada: el entorno, la capacity.

output

Un valor que devuelve: el ID del workspace creado.

data

Algo que ya existe y solo quieres consultar.

locals

Valores calculados que reutilizas: nombres, tags.

module

Un paquete reutilizable: tu template empaquetado.

Con resource y variable ya puedes hacer el 80% de lo que necesitas el primer mes.
