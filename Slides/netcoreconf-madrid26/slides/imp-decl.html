Imperativo vs declarativo: por qué esto te suena

IMPERATIVO · le dices CÓMO

deploy.ps1

$ws = Get-Workspace -Name "Bronze-DEV"
if ($null -eq $ws) {
  $ws = New-Workspace -Name "Bronze-DEV"
  Set-Capacity -Id $cap -Workspace $ws
} else {
  if ($ws.Capacity -ne $cap) {
    Set-Capacity -Id $cap -Workspace $ws
  }
}

Tú escribes todos los if. Tú gestionas todos los casos.

DECLARATIVO · le dices QUÉ

main.tf

resource "fabric_workspace" "bronze_dev" {
  display_name = "Bronze-DEV"
  capacity_id  = var.capacity_id
}

# Quiero que exista así.
# Ya verá Terraform cómo llegar.

Tú declaras el resultado. El motor calcula el camino.

Esto ya lo dominas: SQL también es declarativo. Escribes el SELECT que quieres; no le explicas al motor si hace hash join o nested loop.

14 · Terraform al rescate

Analogía clave para audiencia de datos: Terraform es al portal de Fabric lo que SQL es a un cursor. Declaras el resultado, no el procedimiento. Clics: el lado declarativo y el puente con SQL.
